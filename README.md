# Reducing Uncertainty, Supporting Decisions: A Case Study on Concrete Compressive Strength

Course project for **Principles of Statistical Modeling (MDE-CS-03)**.

This project investigates the Concrete Compressive Strength dataset using statistical modeling techniques to understand data variability, identify outliers, analyze dependencies between variables, and fit probabilistic models.

## Project Contents

- Raw data exploration and visualization
- Outlier detection and discussion
- Marginal distribution analysis
- Distribution fitting using MLE
- Correlation and pairwise distribution analysis
- Gaussian modeling of selected variable pairs
- Statistical interpretation and discussion

## File

- `psm_code.py` – Main project script containing all analyses and visualizations.
